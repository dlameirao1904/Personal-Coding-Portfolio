# 3D

Reconstrução de uma cena a partir de fotografias, mais um visualizador para preparar e guardar modelos 3D.

Há duas partes: `modelsapi`, a API em Python que corre o pipeline de reconstrução, e `transform`, a aplicação Vue que fotografa, mostra e guarda os modelos.

## modelsapi

API em FastAPI. O endpoint `POST /api/reconstruct` recebe um conjunto de imagens. São precisas pelo menos dez. Cada pedido fica numa pasta própria em `scan_process`, com as fotos em `input` e o resultado previsto em `output`.

O pipeline em `reconstruction/` segue a ordem clássica de structure from motion:

1. Pré-processamento das imagens.
2. Extração de features.
3. Matching entre pares.
4. Tracks, para seguir o mesmo ponto ao longo de várias fotos.
5. Geometria dos pares e estimativa de pose.
6. Cheirality, para escolher a pose em que os pontos ficam à frente das câmaras.
7. Poses globais, para pôr todas as câmaras no mesmo referencial.
8. Triangulação, que passa os pontos 2D a coordenadas 3D.
9. Construção do mapa, com câmaras, pontos e observações.
10. Erro de reprojeção e bundle adjustment, para afinar poses e pontos.

`meshing.py` e `exporter.py` existem, mas estão vazios: o pipeline devolve o mapa reconstruído em memória e a resposta HTTP confirma o `scan_id` e as pastas, sem devolver ainda um ficheiro de malha.

## transform

Aplicação Vue, Vuetify e Three.js, com sessão (login, registo, recuperação de palavra-passe). Os modelos guardados passam por uma API no estilo Strapi (`transform-models` e upload de media).

Três ecrãs:

- **Modelos.** Lista do que já foi guardado e entrada para criar um novo.
- **Editor.** Carrega um GLB (pensado para scans do Polycam), muda a escala, centra na origem, liga um modo de linhas de gémeo digital e pode comprimir a saída com Draco. Dá para escolher uma peça, ocultá-la e atribuir-lhe um movimento (rotação no eixo Y ou flutuar). O resultado vê-se no `ThreeViewer`, descarrega-se em GLB e grava-se na API.
- **Scanner.** Abre a câmara, tira pelo menos dez fotografias e envia-as para `POST http://localhost:8000/api/reconstruct`.
